# List of Years in Video Games

An archive of video games organized by year, built from Wikipedia's [List of years in video games](https://en.wikipedia.org/wiki/List_of_years_in_video_games) index and each year's article, with every title tagged by platform so you can filter to just one console's releases for a given year. Years Wikipedia covers thinly are topped up with notable titles from [IGDB](https://www.igdb.com).

**18994 titles** across 39 years (1990-2028), **18985** tagged with at least one platform (2113 of the titles were added from IGDB).

**[Open the interactive filter →](index.html)** -- pick a year and a platform and browse matching titles in the browser (works by opening the file directly, or via GitHub Pages if you enable it in the repo settings -- Settings -> Pages -> Deploy from a branch -> root).

## Coverage notes

- Wikipedia's "X in video games" articles carry an exhaustive month-by-month release table only through **2011**. From 2012 on those lists live in separate "List of video games released in X" articles, which this archive scrapes too (`scripts/scrape_lists.py`), so those years have hundreds of titles each. Earlier years rely on the original articles' tables, which are thinner -- especially in the early 1990s. Years that are still thin are topped up with the most-rated titles IGDB has for them, so their counts reflect notability, not a complete release list.
- 1990, 1991, 1993, 2028 have no structured release table on Wikipedia at all and so contribute no Wikipedia titles (any titles in those years come from IGDB).
- Platform tags come from each article's own abbreviation legend (e.g. "PS2", "WIN") plus a curated lookup table for consistency across years; see `scripts/platforms.py`.

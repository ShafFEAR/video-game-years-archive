# List of Years in Video Games

An archive of video games organized by year, built from Wikipedia's [List of years in video games](https://en.wikipedia.org/wiki/List_of_years_in_video_games) index and each year's article, with every title tagged by platform so you can filter to just one console's releases for a given year. Games with their own Wikipedia article that those tables miss are added from its per-year [video game categories](https://en.wikipedia.org/wiki/Category:Video_games_by_year). Years Wikipedia covers thinly are topped up with notable titles from [IGDB](https://www.igdb.com). IGDB also supplies covers and summaries for many of the listed games.

**34,797 titles** across 39 years (1990-2028), **33,568** tagged with at least one platform. Beyond the year articles' own lists, 17,248 titles come from Wikipedia's category pages and 668 from IGDB.

**[Open the interactive filter →](index.html)** -- pick a year and a platform and browse matching titles in the browser (works by opening the file directly, or via GitHub Pages if you enable it in the repo settings -- Settings -> Pages -> Deploy from a branch -> root).

## Coverage notes

- Wikipedia's "X in video games" articles carry an exhaustive month-by-month release table only through **2011**. From 2012 on those lists live in separate "List of video games released in X" articles, which this archive scrapes too (`scripts/scrape_lists.py`), so those years have hundreds of titles each. Earlier years rely on the original articles' tables, which are thinner -- especially in the early 1990s. Even so, plenty of games with their own article appear in neither, so the archive also adds every game in Wikipedia's "YYYY video games" categories that those tables miss (`scripts/scrape_categories.py`). Years that are still thin are topped up with the most-rated titles IGDB has for them, so their counts reflect notability, not a complete release list.
- Titles added from the category pages take their developer, publisher, genre, release date and platforms from the article's infobox. That infobox lists every platform a game ever reached, so platforms that did not exist yet in the game's year are dropped -- but a later port to an older platform can still show up under the original year, and many of these titles have no release month.
- 12,689 of the 17,248 games added from the category pages have an IGDB record (nearly all with a cover, most with a summary). A game gets one only when IGDB holds it under the same (or an alternative) name in the same or an adjacent year and nothing else fits equally well -- same-name games are common -- so the rest stay text-only rather than risk showing the wrong game.
- 2028 has no structured release table on Wikipedia at all and so contributes no Wikipedia titles (any titles in those years come from IGDB).
- Platform tags come from each article's own abbreviation legend (e.g. "PS2", "WIN") plus a curated lookup table for consistency across years; see `scripts/platforms.py`.

## Rebuilding the data

Each stage reads and writes JSON under `data/`, and every scraper can be re-run on its own (they take a list of years, and resume or skip what is already there):

```
python scripts/scrape_index.py                       # "YYYY in video games" tables      -> data/index/
python scripts/scrape_lists.py                       # "List of video games released in YYYY" -> data/lists/
python scripts/scrape_categories.py                  # "Category:YYYY video games" members     -> data/categories/
python scripts/scrape_categories.py --infoboxes      # developer, publisher, genre, platforms for those articles
python scripts/fetch_igdb.py                         # optional: notable titles from IGDB (needs Twitch credentials in .env)
python scripts/lookup_igdb.py                        # optional: IGDB covers and summaries for the category-sourced games
python scripts/generate_site.py                      # README, years/, platforms/, data/web/ and index.html
```

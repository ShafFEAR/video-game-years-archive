# List of Years in Video Games

An archive of video games organized by year, built from Wikipedia's [List of years in video games](https://en.wikipedia.org/wiki/List_of_years_in_video_games) index and each year's article, with every title tagged by platform so you can filter to just one console's releases for a given year. Years Wikipedia covers thinly are topped up with notable titles from [IGDB](https://www.igdb.com).

**10045 titles** across 39 years (1990-2028), **10036** tagged with at least one platform (4243 of the titles were added from IGDB).

**[Open the interactive filter →](index.html)** -- pick a year and a platform and browse matching titles in the browser (works by opening the file directly, or via GitHub Pages if you enable it in the repo settings -- Settings -> Pages -> Deploy from a branch -> root).

## Coverage notes

- Wikipedia stopped maintaining an exhaustive month-by-month release table on most "X in video games" articles after **2011** -- the sheer volume of releases (digital storefronts, mobile, indies) made that impractical for editors to keep up by hand. For 2012 onward, this archive uses whatever curated release/score table each year's article still maintains (often a "best-reviewed games" chart), so per-year counts drop sharply after 2011 -- that's a real gap in the source data, not a scraper bug. Those thin years are topped up with the most-rated titles IGDB has for them, so their counts reflect notability, not a complete release list.
- A handful of years (1990, 1991, 1993, and 2027-2028) have no structured release table on Wikipedia at all and so contribute no Wikipedia titles (any titles in those years come from IGDB).
- Platform tags come from each article's own abbreviation legend (e.g. "PS2", "WIN") plus a curated lookup table for consistency across years; see `scripts/platforms.py`.
